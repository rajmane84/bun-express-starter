# Scafolder

A lightweight package scaffolding tool for quickly generating project structures and boilerplate code.

## Installation

```bash
npx create-bun-express-app
```

## Features

- Quick project scaffolding
- Multiple template support
- Customizable templates
- Zero configuration setup

## Templates

- `react` - React application template
- `node` - Node.js backend template
- `next` - Next.js full-stack template

## Configuration

```json
{
  "templates": "./templates",
}
```
